# LOUP GAROU — Legends of the Village

A standalone Godot 4.4 Android game project for the classic Werewolf social-deduction party game.

## Current prototype
- Arabic, French and English interface selection.
- Offline 6-seat match prototype.
- Secret role assignment and basic night/day/voting loop.
- Roles currently defined: Werewolf, Seer, Witch, Hunter, Guard and Villager.

## Planned milestones
1. Finish and test complete offline rules, role abilities, AI behavior and configurable player counts.
2. Add local pass-and-play and accessibility/polish.
3. Add online rooms, matchmaking, reconnect handling and server-authoritative game state.
4. Add Android export, store assets, privacy and release checks.

## Build
Open this folder in Godot 4.4.1 or later and run `scenes/main.tscn`.
Android export requires Android SDK/JDK and matching Godot export templates.
